ℹ️ Sobre o RARETECH

O RARETECH é um protótipo acadêmico desenvolvido para demonstrar como um sistema de informação pode auxiliar no monitoramento dos impactos ambientais relacionados à mineração e ao processamento de Terras Raras.

Nesta versão, os dados automáticos são simulados para representar sensores ambientais. Em uma implementação real, o sistema poderia receber informações de sensores IoT, dispositivos ESP32, APIs e bancos de dados.

RARETECH • Projeto acadêmico de Análise e Desenvolvimento de Sistemas

⚠️ Dados demonstrativos — não provenientes de sensores reais.
